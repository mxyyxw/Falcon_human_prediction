四、技术架构
================================================================================

StreamVLN Policy 层次:
  
  StreamVLNPolicy (NetPolicy)
    │
    ├─ StreamVLNNet (Net)
    │   │
    │   ├─ StreamVLNForCausalLM (Qwen2 + LLaVA)
    │   │   ├─ Vision Tower (图像编码)
    │   │   ├─ MM Projector (多模态投影)
    │   │   └─ Language Model (文本生成)
    │   │
    │   └─ habitat_compat (适配层)
    │       ├─ 观测转换
    │       ├─ 动作映射
    │       └─ 传感器适配
    │
    └─ Falcon Policy Interface
        ├─ act()
        ├─ forward()
        └─ from_config()

六、使用示例
================================================================================

Python API:
```python
from habitat_baselines.rl.ddppo.policy import StreamVLNPolicy

policy = StreamVLNPolicy.from_config(
    config=config,
    observation_space=obs_space,
    action_space=action_space
)
action = policy.act(observations)
```

配置文件:
```bash
python -m habitat_baselines.run \
    --config-name=vln/streamvln_inference \
    habitat_baselines.rl.policy.main_agent.model_path=/path/to/model
```

直接推理:
```python
from habitat_baselines.rl.ddppo.policy.streamvln_policy import StreamVLNNet

model = StreamVLNNet(...)
actions, output = model.generate_action_sequence(
    rgb=image, instruction="go to kitchen"
)
```
